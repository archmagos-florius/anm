# Seed Menu Item Image Attributions

These local demo images were downloaded once from Wikimedia Commons and committed as static seed assets.
`scripts/seed_menu_items.php` only seeds database paths to these existing files; it does not download images during setup.
Review each license before using the seeded images in production marketing materials.
